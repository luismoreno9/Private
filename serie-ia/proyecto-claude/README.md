# Proyecto de Claude: SERIE IA

Material para crear el Proyecto "SERIE IA" en claude.ai, con la misma estructura que los demás proyectos.

| Campo del proyecto | Qué poner |
|---|---|
| Nombre | `SERIE IA` |
| Descripción | Serie de comedia por capítulos generada con IA (Seedance 2.5 en Higgsfield) para IG, TikTok y Shorts. |
| Instrucciones | Pegar el contenido de [instrucciones.md](instrucciones.md) |
| Conocimiento | Subir [SERIE-IA-conocimiento.md](SERIE-IA-conocimiento.md) |

Cuando cambie la biblia o el plan, vuelve a generar el archivo de conocimiento y súbelo otra vez, sustituyendo el anterior:

```bash
bash serie-ia/proyecto-claude/generar-conocimiento.sh
```
